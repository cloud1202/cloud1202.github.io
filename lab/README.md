# lab — 독립 페이지 공간

이 폴더는 Jekyll 블로그와 **의도적으로 분리된** 독립 공간입니다.
추후 별도 저장소나 다른 호스팅으로 옮길 예정입니다.

## 왜 Jekyll이 손대지 않는가

`index.html` 맨 위에 front matter(`---`)가 없습니다.
Jekyll은 front matter 없는 파일을 Liquid 처리도, 레이아웃 적용도 하지 않고
`_site/`로 **바이트 그대로 복사**합니다. 따라서 `_layouts`, `_includes`,
`_sass`, `_config.yml`의 `defaults` 어느 것도 이 폴더에 영향을 주지 않습니다.

## 지켜야 할 규칙

- **front matter 금지.** `---`를 추가하는 순간 Jekyll이 처리 대상으로 삼습니다.
- **Liquid 태그 금지.** `{{ site.baseurl }}`, `{% raw %}{% ... %}{% endraw %}` 같은 문법을 쓰지 않습니다.
  옮긴 뒤 빌드가 없는 환경에서 문자열이 그대로 노출됩니다.
- **상대경로만 사용.** `./css/style.css` 처럼 씁니다. 루트 절대경로(`/css/...`)를 쓰면
  다른 서브경로로 옮길 때 전부 깨집니다.
- **블로그 자산 참조 금지.** `/assets/...` 아래 파일을 끌어다 쓰면 이전 시 함께 옮겨야 합니다.
  필요한 파일은 이 폴더 안에 복사해 둡니다.

## 확인 방법

Jekyll 서버가 필요 없습니다. `lab/index.html`을 브라우저로 직접 열면 됩니다.

배포 후 주소: `https://cloud1202.github.io/lab/`
(`<meta name="robots" content="noindex, nofollow">`로 검색엔진 색인은 막아둔 상태입니다.
정식 공개할 때 그 한 줄을 지우면 됩니다.)
